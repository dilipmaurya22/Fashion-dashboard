How it works

  • Works with 58mm / 80mm ESC/POS thermal receipt printers connected as a USB / COM port or on the network.
  • Once connected, the Print button on any bill sends the receipt straight to the printer — no dialog.
  • The printer is remembered — after a page refresh, it reconnects on its own (no port list to pick from again).
  • Printing is handled by the New Look Print Helper app running on this computer (localhost:9100) — keep it running.
  • Printer not in the USB list? Set it up once in Windows: Devices and Printers → right-click the printer → Ports.
